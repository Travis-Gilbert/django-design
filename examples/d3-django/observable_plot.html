{% comment %} Observable Plot + Django Integration ===================================== Observable Plot is a higher-level charting library built on D3 that removes the boilerplate of scales, axes, and layouts. It is ideal when you want a chart quickly without the full D3 ceremony. Key advantages over raw D3: - Declarative API: describe what to plot, not how to draw it - Automatic scales, axes, and legends - Built-in faceting for small multiples - Much less code for standard chart types Trade-offs: - Less control over animation and interaction - Harder to customize beyond Plot's design vocabulary - Adds another dependency (though it depends on D3 internally) This template demonstrates Plot equivalents for the same data shapes served by the Django endpoints in api_views.py.
