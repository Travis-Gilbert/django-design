{# ====================================================================== Pattern 5: Delete with confirmation ====================================================================== hx-delete sends a DELETE request. hx-confirm shows a native browser confirm dialog before the request is sent. If the user cancels, no request is made. hx-swap="outerHTML swap:500ms" means: - Replace the target element (the table row) with the response. - Wait 500ms before performing the swap, allowing a CSS transition (like a fade-out) to play. The server returns an empty response body, which effectively removes the row from the DOM. CSS for the fade-out: tr.htmx-swapping { opacity: 0; transition: opacity 500ms; } ====================================================================== #} {# See the delete button in Pattern 4 above.
